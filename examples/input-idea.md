# Example Input Idea

Turn this idea into a review-ready PRD:

We need a merchant coupon budget control feature.

Business context:

- Operators create coupon campaigns for merchants.
- Some campaigns exceed the expected budget because issuance and redemption are not controlled together.
- Finance wants a clear cap before launch.
- Risk control wants visibility when a campaign is close to over-issuance.

Initial goal:

- Let operators configure a campaign budget cap.
- Prevent obvious over-issuance.
- Show risk before launch.
- Produce engineering-ready rules, flows, acceptance criteria, and an HTML review artifact.
