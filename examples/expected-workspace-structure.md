# Expected Workspace Structure

After a complete PRD workflow, the workspace should contain a feature folder like this:

```text
docs/prd-workspace/merchant-coupon-budget-control/
  00-intake.md
  01-boundary.md
  02-rules.md
  03-flows.md
  04-pages.md
  05-admin-config.md
  06-data-acceptance.md
  07-risk-review.md
  08-review-ready-prd.md
  design-language.md
  09-review.html
```

The Markdown files are the source of truth. `09-review.html` is the readable review artifact.
